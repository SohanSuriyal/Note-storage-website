# NoteVault

A browser-only personal notes organizer.

## Features
- Subjects → Topics → Notes
- PDF and handwritten image uploads
- Drag & drop upload
- IndexedDB local storage
- PDF viewer and image viewer
- Favorites
- Recent notes
- Search
- Light/dark mode
- Responsive UI

## Run
Open `index.html` in a modern browser.

No server or database is required. Notes stay in the browser's IndexedDB.

Google sign-in is a placeholder because real OAuth requires a configured client ID/backend and is not necessary for local-only storage.
